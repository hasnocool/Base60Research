# Data directory

- raw/: user-managed source datasets; ignored by Git.
- processed/: derived data with reproducible transformation scripts.
- manifests/: provenance manifests (source URL, access date, license, units, timezone, sampling rate, missing-data policy and SHA-256).

Do not commit restricted or large third-party datasets. Store source links and retrieval instructions instead. Synthetic data is generated by the package and does not need to be stored.
